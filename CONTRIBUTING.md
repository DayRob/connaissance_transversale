# Contribuer

Merci de votre intérêt ! Toute aide est la bienvenue : correction d'une erreur, précision, nouvelle fiche.

## Ajouter une fiche

1. Copiez `templates/fiche.md` dans le bon dossier de `notes/`.
2. Nommez le fichier d'après la notion : `notes/reseaux/Modele OSI.md`.
3. Une fiche = une notion. Reliez-la aux notions voisines avec `[[Nom de la fiche]]`.
4. Citez vos sources dans l'en-tête `sources`.

## Proposer une modification

1. Forkez le dépôt et créez une branche (`git checkout -b fiche/modele-osi`).
2. Faites vos modifications et un commit explicite.
3. Ouvrez une Pull Request en décrivant le changement.

## Style

- Français clair, phrases courtes.
- Pas de contenu copié sans autorisation : reformulez et citez.
