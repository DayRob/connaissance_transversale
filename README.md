## Pourquoi ce projet ?

Au fil de mes études et de mes projets, j'ai accumulé des notes sur de nombreux sujets : développement, réseaux, cybersécurité, bases de données, méthodes de travail… **Connaissance transversale** rend cette base disponible en open source, pour qu'elle serve à d'autres étudiants, curieux et professionnels.

Le principe : des notes courtes, une notion par fichier, reliées entre elles. On peut les lire directement sur GitHub, les ouvrir comme coffre [Obsidian](https://obsidian.md) pour naviguer dans le graphe de liens, ou les utiliser comme source pour des outils (moteur de recherche, RAG, génération de quiz…).

## Organisation

```
connaissance_transversale/
├── notes/               # Les fiches, rangées par grand domaine
│   ├── developpement/
│   ├── reseaux/
│   ├── cybersecurite/
│   ├── bases-de-donnees/
│   └── methodologie/
├── templates/           # Modèle de fiche
└── CONTRIBUTING.md      # Comment contribuer
```

## Utilisation

- **Sur GitHub** : parcourez le dossier `notes/`.
- **Avec Obsidian** : clonez le dépôt puis *Ouvrir un dossier comme coffre*.
  ```bash
  git clone https://github.com/DayRob/connaissance_transversale.git
  ```
