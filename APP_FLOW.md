# APP FLOW — Connaissance transversale

> Ce dépôt est une **base de connaissances open source**, pas une application : les rubriques techniques (flux, schéma, design) décrivent ici l'organisation du contenu, les parcours de lecture et de contribution, et les conventions de rédaction.

## 1. Lecture

```
README ──► notes/<domaine>/ ──► fiche
                                  ├─ En bref (définition)
                                  ├─ Explication ──► Exemple
                                  ├─ À retenir
                                  └─ Voir aussi ──► fiches voisines
```

## 2. Lecture dans Obsidian

```
git clone ──► « Ouvrir un dossier comme coffre »
  ──► navigation par liens [[…]] ──► vue graphe ──► recherche par tag / domaine
```

## 3. Contribution

```
Fork ──► branche (fiche/<nom>)
  ──► copier templates/fiche.md dans notes/<domaine>/<Notion>.md
  ──► remplir l'en-tête et les sections ──► relier aux fiches voisines ──► citer les sources
  ──► commit ──► pull request ──► relecture ──► fusion
```

## 4. Correction

```
Erreur repérée ──► issue ou modification directe ──► pull request ──► fusion
```
