# DESIGN BRIEF — Connaissance transversale

> Ce dépôt est une **base de connaissances open source**, pas une application : les rubriques techniques (flux, schéma, design) décrivent ici l'organisation du contenu, les parcours de lecture et de contribution, et les conventions de rédaction.

## 1. Ton

Clair, accessible, en français, sans jargon inutile : on écrit pour quelqu'un qui découvre la notion.

## 2. Structure d'une fiche

| Section | Rôle | Longueur indicative |
|---|---|---|
| **En bref** | Définition | 2-3 phrases |
| **Explication** | Fonctionnement | Quelques paragraphes |
| **Exemple** | Cas concret, code, schéma | 1 exemple minimum |
| **À retenir** | Points clés | 2-5 puces |
| **Voir aussi** | Liens vers les fiches voisines | 1+ lien |

## 3. Règles de rédaction

- Une fiche = une notion ; si une section s'allonge, elle devient une fiche à part.
- **Gras** pour le terme défini, *italique* pour les termes étrangers.
- Tableaux pour comparer, blocs de code avec langage pour le code.
- Reformuler et citer ; jamais de copie.
